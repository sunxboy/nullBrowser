# Legacy one-off patch scripts

These are historical, single-use scripts that were used to bulk-edit the UI,
themes, menus, shortcuts, and fonts during earlier development. They are **not**
part of the build or runtime and nothing in the app references them.

They are kept here (moved out of `Browserapp/`) for archival reference only. Do
not add new one-off patch scripts here — make the edits directly in source.
